1. Project Objective

The purpose of this analysis is to understand customer churn behavior, identify customer segments associated with higher churn, and evaluate revenue patterns.

3. Business Questions

Which customer segment has the highest churn rate?
Which contract type has the best customer retention?
Does customer tenure influence churn?
Which payment methods are associated with higher churn?
Does technical support availability relate to customer retention?
Which states generate the highest revenue?
Which subscription type contributes the most revenue?


4. Recommendations

The following strategies can be evaluated based on the actual analysis results:

Introduce targeted retention campaigns for high-churn segments.
Provide loyalty programs to encourage long-term subscriptions.
Review pricing plans for customers with high monthly charges.
Improve technical support for customers who need assistance.
Monitor churn rates by contract and subscription type.
Use customer segmentation to develop personalized offers.


5. Final Conclusion

This project demonstrates how data analytics can help a subscription-based business understand customer behavior, identify churn patterns, monitor revenue, and support customer retention decisions.
